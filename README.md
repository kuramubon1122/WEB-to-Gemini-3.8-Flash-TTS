# 🎙️ Gemini 3.8 Flash TTS Studio

Google の最先端モデル **Gemini 3.8 Flash TTS** および **Gemini 3.8 Flash-Lite TTS** をブラウザだけで利用できる、音声合成＆音声クローン（Voice Replication）Webアプリケーションです。

🌐 **サービスURL**: [https://tts.www-co-jp.com](https://tts.www-co-jp.com)

---

## 🚀 すぐに利用する（Web版）

面倒なインストールや環境構築は不要です。以下のリンクからブラウザでアクセスするだけですぐにご利用いただけます。

👉 **[https://tts.www-co-jp.com](https://tts.www-co-jp.com)**

> ※ PC / スマートフォンの最新版ブラウザ（Google Chrome, Edge, Safari など）に対応しています。  
> ※ マイク録音機能を利用する場合は、アクセス時にマイクの使用許可を「許可」にしてください。

---

## ✨ 主な機能と特徴

- 🚀 **完全クライアントサイド動作（サーバーレス）**
  - アプリはすべてブラウザ上で動作します。入力したテキストや音声データ、APIキーが運営者側のサーバーに保存・送信されることはありません。
- 🗣️ **Gemini 3.8 音声クローン（Voice Replication）**
  - **学習用音声（約20秒）** と **認証用音声（Google公式同意文）** をブラウザ上で録音またはファイルアップロード（.wav, .mp3, .m4a）するだけで、あなた自身の声を登録可能。
  - クライアント側（Web Audio API）で自動的に **24kHz LINEAR16 Mono WAV** にリサンプリング・エンコードするため、Google API の要求仕様に完全適合。
  - 完了後の誤操作を防ぐ排他制御（無効化ボタンに1秒カーソルを合わせると理由を表示する親切設計）。
- 📝 **ブロック形式のマルチTTSエディタ**
  - セリフや段落ごとに「＋」ボタンでブロックを追加可能。
  - ブロックごとに **クローンした声** / **Gemini 3.8 Flash TTS（12種類の公式ボイス）** / **Gemini 3.8 Flash-Lite TTS** を個別に指定可能。
  - 読み上げ方のイメージ（プロンプト・演技トーン指定）や、`<laugh>`, `<short pause>` などの感情表現タグのワンクリック挿入に対応。
- 💾 **ブラウザ内（localStorage）での安全なデータ管理**
  - APIキー、作成したプロジェクト、クローンしたボイスIDはお使いのブラウザ内部にのみ保管されます。
- 🎨 **モダンで使いやすいUI**
  - 折り畳み式サイドバー、波形シークバー付きカスタムプレイヤー、ダークモード / ライトモード対応。

## 📖 使い方ガイド

### Step 1: Gemini API キーの設定
1. [https://tts.www-co-jp.com](https://tts.www-co-jp.com) にアクセスします。
2. 初回アクセス時に表示されるモーダル、または右上の「APIキー未設定」ボタンをクリックします。
3. [Google AI Studio](https://aistudio.google.com/app/apikey) で取得したご自身の API キーを入力し、「保存して利用開始」を押します。

---

### Step 2: 音声クローン（Voice Replication）の作成
右上の **「音声作成」** ボタンをクリックすると作成画面が開きます。

1. **音声名の入力**: 作成する声の名前（例: `私のナレーション音声A`）を入力します。
2. **学習用音声の準備（約20秒）**:
   - 「録音開始」を押して20秒程度話すか、既存の音声ファイル（.wav / .mp3 / .m4a）をアップロードします。
3. **認証用音声の準備**:
   - 画面に表示されている公式の同意文を読み上げます。
     > *「私はこの音声の所有者であり、Google がこの音声を使用して音声合成モデルを作成することを承認します。」*
   - 「認証用録音開始」を押して読み上げるか、該当文言を読み上げた音声ファイルをアップロードします。
4. **クローン登録**:
   - 両方の音声が揃うと「音声合成開始」ボタンが有効化されます。
   - ボタンを押すと Gemini API にリクエストが送信され、自動発行されたボイスIDがブラウザに保存されます。

---

### Step 3: テキスト読み上げ（TTSスタジオ）
1. **文章の入力**: 「読み上げる文章」にテキストを入力します（`<short pause>` などの感情タグも挿入可能）。
2. **スタイルの指定**: 「読み上げ方のイメージ」にトーン（例: `明るく元気なナレーション`）を入力またはプリセットから選択します。
3. **ボイスの選択**: 上部のドロップダウンから「登録済みクローン音声」または「Gemini標準ボイス（Puck, Kore など）」を選択します。
4. **生成 & 再生**: 「音声生成」ボタンを押すと音声が生成され、プレイヤーでの再生・シークバー操作・WAVダウンロードが可能です。
5. **ブロックの追加**: 「＋ 新しいTTSブロックを追加」を押すことで、複数人の会話劇や長文のパート分け編集が可能です。
